How it differs from a memory tool

recortex gives the people doing the work a shared record. Claude can use that same record to answer a question or flag a relevant failure while a decision is still open.

FeatureA typical memory toolrecortex
Where it lives A private store that only the assistant reads Your project's GitHub issues, which your team can read with or without the plugin
What it keeps Notes and preferences Results with their evidence, decisions with their reasons, and dead ends, linked to each other
What comes out Context for a conversation A cited answer while you decide, a project checklist that follows progress, and a dashboard where you can inspect the sources
Who it is for One person and their assistant The whole team can follow the record. You name who can make decisions and choose whether to keep a task board.

Start in two commands

{{cmd claude plugin marketplace add {{repo}} claude plugin install recortex@recortex }}

You need Claude Code, the GitHub CLI gh (signed in), Python 3.8 or newer and bash. The plugin installs nothing else.

  1. 1Open Claude Code in your project and say Set up the record for this project.
  2. 2Answer a few multiple-choice questions. Nothing is written before you confirm.
  3. 3Choose how much the observer does on its own: Everything, Assistant or Notes only. It does not run until you choose.
  4. 4When you make your first real decision, use /recortex:record to post it on GitHub, even in shadow mode. This gives the observer a topic for later notes.

The full steps

Ask it directly

The observer works without being asked. Five short commands, and an agent you can mention, are for when you want something now.

  • /recortex:recordRecord what just happened, or what you name.
  • /recortex:askAnswer a question from the record, with its sources.
  • /recortex:todoShow the to-do list with its checkmarks, or add to it.
  • /recortex:statusWhere things stand, what is next, what waits for your yes.
  • /recortex:usageWhat the plugin used, in tokens and calls.
  • @agent-recortex:askThe same answers from a read-only agent, for a longer question.

Who it is for

For people who work in Claude Code and keep a project on GitHub, on their own or with a team. A developer can find the restart test that ruled out a retry queue. A field researcher can find why the team excluded observations with missing site labels and who made that call.
