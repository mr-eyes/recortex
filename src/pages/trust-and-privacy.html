Trust and privacy

What stays on your machine, what goes to GitHub, and what a session is shown. Text that came from outside is treated as data and never as instructions.

Where things live

  • Stays on your machine

    The local index, which is a copy of the record, your key, the observer's queue and approvals, your trusted list, your writing mode, drafts that wait, usage counts and the private page.

    All of it is in private folders, mode 0700, with files at mode 0600, and never in your project.

  • Goes to GitHub

    Notes, topic bodies, the hub, labels, task lists, and, if you choose them, a board and the versions branch. They live in the repository you picked, visible to everyone who has access to it.

    The observer posts only what a second pass accepted, with no image, HTML, mention, outside link, local path, user name or email address.

  • Shown to a session

    A short brief, only from a repository you trust, inside a frame that says it is data. The observer's models see the conversation and the record's context, never tool output, files or web pages.

Pages that hold private text, such as the private page of a private repository, stay in your private folder. Do not copy them anywhere shared.

Untrusted text

Anyone with write access to a repository can edit a hub, and on a public repository anyone can open an issue. So everything read from GitHub, from the project folder, from the index and from the environment is data. Claude is told never to follow a command it finds there.

  • You trust a repository firstA session is shown nothing from a repository until you add it to your own trusted list, a file in your own configuration folder. Nothing inside a project can add to it.
  • Only allowed authors countA status note counts only when an allowed account wrote it and nobody edited it. One that fails the check is counted and never shown.
  • Text sits inside a frameProject text is wrapped in BEGIN/END PROJECT STATUS DATA lines, text that imitates them is defused, and the brief is cut at a fixed size.
  • A project cannot turn the observer onIts file can only switch the observer off. The choice of level is kept on your machine.

Holds and the confirmations that ask for your own terminal guard against mistakes. A session with shell access can still get around them. The real gates are your answers in a dialog and your own terminal. The full security model lists every rule and what it prevents.

Who decides

  • At setup you name who can make decisions. A decision is quoted word for word, with its date, time and zone.
  • Several settings are each person's own, on their own machine: the trusted list, the writing mode, the observer's level and whether a field sheet is approved.
  • For a repository owned by an organization, list the people who post status notes in your trusted list, because the owner is then not a person.
  • Keep one writer per issue. Update every machine on a team before the observer opens the first task, because older versions read task notes as plain comments.

What it costs

Tokens and calls. No dollar figure is shown anywhere, because none applies under a Claude subscription. The observer's calls run under your own Claude sign-in and count against your usage limits, within the daily caps on How it works. A typical day is about 36 calls, which is about what the 1.4.0 observer used.

If ANTHROPIC_API_KEY or a provider variable is set, the calls are billed to that key or provider instead. Setup says so, and names the variable, never its value. You can lower every cap with observer.py limits. /recortex:usage and the page's last view show what was used. What the hooks add to your sessions is estimated; the main session's own work on the record is not measured.

What it never does

On GitHub

  • Delete an issue, a comment or a label
  • Edit a note it posted
  • Add the project scope to your login

On your machine

  • Sign in or install anything for you
  • Write the text of a paper without your yes
  • Use any service other than GitHub and your Claude sign-in

This site uses no analytics and no cookies, and loads nothing from another server. It keeps one thing in your browser: your choice of light or dark.
